# zh
## would like：禮貌地說「想要」
would like 比 want 更客氣，用在點餐、請求、提供。
表：三種用法
| 用法 | 例句 |
|---|---|
| + 名詞 | I'<b>d like</b> a coffee. |
| + to 原形 | I'<b>d like to</b> order. |
| 問句（提供／邀請） | <b>Would you like</b> some tea? |
## 重點
| 規則 | 例子 |
|---|---|
| 問句把 would 移到句首 | <b>Would</b> you like…?（✗ Do you would like） |
| 縮寫 | I would → <b>I'd</b> |
> to 後面接<b>原形動詞</b>，不是名詞：✗ I'd like to coffee → ✓ I'd like <b>a coffee</b> / I'd like to <b>drink</b> coffee。
# mc
Q: I ___ a glass of water, please. || 我想要一杯水。
A: would like* | am like | like to
W: would like + 名詞。
Q: ___ you like to come with us? || 你想和我們一起來嗎？
A: Do | Would* | Are
W: 邀請用 Would you like to…？
Q: She'd like ___ a new phone. || 她想買一支新手機。
A: buy | to buy* | buying
W: would like to + 原形 buy。
# err
S: [Do you would|Would you] like some cake? || 你想要一些蛋糕嗎？
W: would like 問句用 Would you…？
S: I'd [want|like] a coffee, please. || 我想要一杯咖啡。
W: would 後面用 like（I'd like）。
S: I'd like to [dinner|have dinner] now. || 我想現在吃晚餐。
W: to 後面接原形動詞 have。
