# zh
## should have + 過去分詞：早知道…
should have + 過去分詞表示「過去應該做卻沒做」，帶懊悔或批評的語氣。
表：兩種
| 說法 | 意思 | 例句 |
|---|---|---|
| should have + V3 | 過去該做卻沒做 | I <b>should have studied</b>. |
| shouldn't have + V3 | 過去不該做卻做了 | I <b>shouldn't have said</b> that. |
## 和現在的 should 比一比
| 情況 | 例句 |
|---|---|
| should（現在建議） | You <b>should</b> rest. |
| should have（過去懊悔） | You <b>should have</b> rested. |
> 口語常說 <b>should've</b>；但別因為發音像就寫成 ✗ should <b>of</b> → ✓ should <b>have</b>。have 後面一定接過去分詞（gone, done, seen）。
# mc
Q: I'm so tired. I ___ to bed earlier. || 我好累，早該早點睡。
A: should go | should have gone* | should went
W: 過去懊悔 → should have + 過去分詞。
Q: You ___ me the truth. || 你早該告訴我實話。
A: should tell | should have told* | should have tell
W: should have + 過去分詞 told。
Q: That was mean. You ___ that. || 那很過分，你不該那樣說。
A: shouldn't say | shouldn't have said* | shouldn't said
W: 不該做卻做了 → shouldn't have + 過去分詞。
