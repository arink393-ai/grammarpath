# zh
## 連接詞：把想法連起來
連接詞連接兩個字、片語或句子。五個最常用的：
表：五個連接詞
| 連接詞 | 功能 | 例句 |
|---|---|---|
| and | 並列、增加 | tea <b>and</b> coffee |
| but | 轉折、相反 | cheap <b>but</b> good |
| or | 選擇 | tea <b>or</b> coffee? |
| so | 結果 | It rained, <b>so</b> we stayed. |
| because | 原因 | We stayed <b>because</b> it rained. |
## so 和 because 的差別
| 連接詞 | 連接 | 例句 |
|---|---|---|
| because | 原因（回答 why） | I'm tired <b>because</b> I ran. |
| so | 結果 | I ran, <b>so</b> I'm tired. |
> 中文「因為…所以…」兩個都說，但英文 <b>because 和 so 只能留一個</b>：✗ Because it rained, so we stayed. → ✓ Because it rained, we stayed.
# mc
Q: I was hungry, ___ I made a sandwich. || 我餓了，所以做了三明治。
A: because | but | so*
W: 表結果 → so。
Q: He's rich ___ unhappy. || 他有錢但不快樂。
A: and | but* | so
W: 轉折 → but。
Q: We cancelled the trip ___ it snowed. || 因為下雪，我們取消了旅行。
A: so | because* | but
W: 表原因 → because。
# err
S: She is smart [but|and] kind. || 她既聰明又善良。
W: 並列、增加用 and。
S: I stayed home [because of|because] I was sick. || 我因為生病待在家。
W: because 後接句子（because of 後接名詞）。
S: Because it was late , [so I left|I left]. || 因為很晚了，我就離開了。
W: because 和 so 不可並用。
# mk
