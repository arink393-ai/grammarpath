# zh
## 第二條件句：與現在事實相反的假設
第二條件句用來假設<b>現在或未來不太可能、或與現實相反</b>的情況。雖然用過去式，但說的是<b>現在</b>。
公式：<b>If + 過去簡單式, would / could / might + 原形動詞</b>
<span class="en">If I <b>had</b> a million dollars, I <b>would travel</b> around the world.</span>（如果我有一百萬，我會環遊世界——但我現在沒有。）
表：第一 vs. 第二條件句
| | 第一條件句 | 第二條件句 |
|---|---|---|
| 可能性 | 真的有可能 | 不太可能、與事實相反 |
| if 子句 | 現在式 | <b>過去式</b> |
| 主要子句 | will + V | <b>would</b> + V |
| 例句 | If it <b>rains</b>, I <b>will</b> stay home. | If I <b>were</b> a bird, I <b>would</b> fly. |

## be 動詞一律用 were
在假設語氣中，be 動詞不論主詞是誰，都用 <b>were</b>（正式寫作、考試的標準用法）：
表：were 的用法
| 主詞 | 例句 |
|---|---|
| I | If I <b>were</b> you, I would apologize. |
| he / she / it | If she <b>were</b> here, she would help us. |
| you / we / they | If they <b>were</b> rich, they would buy a house. |
註：If I were you（如果我是你）是給建議的常用句型。口語中 If I was 也聽得到，但考試請用 were。

## 主要子句的助動詞
| 助動詞 | 意思 | 例句 |
|---|---|---|
| would | 會 | If I had time, I <b>would</b> help you. |
| could | 能夠 | If I spoke French, I <b>could</b> work in Paris. |
| might | 可能會 | If you asked him, he <b>might</b> agree. |

## if 子句不能用 would
| ✗ 錯誤 | ✓ 正確 |
|---|---|
| If I would have money, I'd travel. | If I <b>had</b> money, I'd travel. |
| If I won, I will quit my job. | If I won, I <b>would</b> quit my job. |
> 倒裝寫法（較正式）：<b>Were I</b> you, I would accept the offer.

W: 第二條件句的主要子句用 would + 原形。

A: win | won* | will win
W: 與現實相反的假設，if 子句用過去式。

A: will fly | would fly* | flew
W: 主要子句用 would + 原形。
