# Illustrated nouns

45 original food and drink icons generated with the built-in OpenAI imagegen tool.
The exact three generation prompts are saved in `prompts.json`.
Each source PNG is a 1536 × 1024 atlas with five columns and three rows.
`NOUN_ART_KEYS` in index.html defines the row-major ordering; CSS displays and splits the icons without editing the original images.

The three photographs were supplied by the user for embedding in this lesson:

- bread-photo.jpg: images-3.jpeg
- meat-photo.jpg: istock-1443190699-modified-b4be7b7e-25e9-4438-a2bd-4185936ecf29.jpg
- cheese-photo.jpg: Blog-3.jpg

The lesson distinguishes mass nouns from countable units. Divisibility is an everyday illustration, not a universal grammar rule or a claim of physical infinite divisibility. The interactive demonstration does not award XP or modify student progress.
